## Settings audit

`settings_audit: not_applicable`. Read all Source/*.cs and the three owned Defs.
The mod automatically picks up, unfolds, folds and swaps traits according to its
fixed original balance: +2 speed, fixed recipe and terrain rules. The 15-tick interval
is an implementation detail. These values are not documented user configuration or
unfinished configurable features. There is no concrete need to expose every balance
constant for this faithful port.
FoldingSkateboardMod inherits Mod and only registers Harmony patches: no ModSettings,
GetSettings, SettingsCategory or DoSettingsWindowContents implementation. No
MainButtonDef, settings window or settings shortcut exists in the XML or C#.
FoldingSkateboardGameComponent stores suspended pawn traits per save, not settings.
No empty page/shortcut is introduced. Option defaults, input limits, settings persistence,
reset and shortcut integration tests are not applicable. No RIMMSQOL or other
customization integration was run or certified. Gameplay trait persistence remains pending.
