## Findings

1. **Defect, corrected: the description made a false claim and ended on a bare URL.** It said the port
   was made under "in-game testing"; the mod has never been run in game. `PUBLISHING.md` also wants
   the description to end on `Source code on GitHub`. Corrected in the repository (`6b7fbdd`). **The
   Steam page of item 3806761118 was created from the earlier text and still carries it**: a later
   `About.xml` change never reaches the page, only `update_description` of a publish or a hand edit does.
2. **Convention applied: `renew` left the packageId** (`6364ed8`), `nelim.foldingskateboardrenew` ->
   `nelim.foldingskateboard`. `PUBLISHING.md` of 2026-09-27 keeps it out of a mod that is not yet public,
   and the owner told A Certain Series' session the same today. The item is only pre-published and
   private; `ModsConfig.xml`, the saves and the other mods were checked and none names the id. It is
   reversible until publication and not after. The 0.1.0 item keeps the old id until 1.0.0.
3. **Uncommitted work found and committed.** Fifteen days of changes, including everything the 0.1.0
   upload carried, sat in the working tree. `Add published Workshop file ID for 0.1.0` (`bf286f2`) is the
   commit of that version, and the commit before it holds the uploaded tree less the `.dds` files.
4. **The `done` of 2026-09-13 does not hold against today's `AUDIT.md`**: its evidence was the scenarios,
   the automated tests and the XML checks, and it did not name the Pickle suite. The stage goes back
   to `preTest`; the earlier decision is kept in `STATUS.md` as history.
5. **The original has no repository.** No link from its `About.xml`, its page or its author's profile;
   no GitHub result for the mod or its packageId; an organisation `silkcircuit` exists with no public
   repository and is not evidence of anything. The port began from the `Source/` folder that the
   Workshop payload ships, so there is nothing to fork and no pull request to send. The page says
   "RimWorld 1.5+", posted 2025-01-25, last updated 2025-01-29; it does not name 1.6, so the source
   stays `silent` under the workflow's definition (reserve B).
6. **The image tool is named and verified.** Both source renders carry a C2PA manifest whose software
   agent is OpenAI's `gpt-image` (icon 2026-09-11, showcase 2026-09-12). The description and
   `ATTRIBUTION.md` now say so.
7. **Housekeeping.** Four `.dds` caches written by the game beside the PNGs on 2026-09-23 were never
   tracked; `*.dds`, `*.ico`, `desktop.ini` and the evidence folders are ignored (`bddace8`); a
   `Mod/desktop.ini` exists on disk (ignored, outside every commit). Disk evidence trimmed: a superseded
   DLL copy and a duplicate of the preview were deleted after listing (both under `.build/`); no
   Pickle report exists for this mod, so no archive of the launcher was touched.
